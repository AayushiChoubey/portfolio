# Aayushi Choubey — Distributed Systems & Backend Engineering Portfolio

Live-ready portfolio built for **Aayushi Choubey** (Member of Technical Staff @ Oracle OCI | B.Tech IIT Indore '24).

## How to Update Your Existing GitHub Portfolio (`AayushiChoubey/Portfolio-website`) in 60 Seconds

1. Clone your existing portfolio repository:
   ```bash
   git clone https://github.com/AayushiChoubey/Portfolio-website.git
   cd Portfolio-website
   ```
2. Replace the root `index.html` with the generated `index.html` from this package (and place your 1-page resume PDF in the folder as `Aayushi_Choubey_Resume.pdf` if you want a direct PDF download button).
3. Commit and push to `main`:
   ```bash
   git add index.html
   git commit -m "Upgrade portfolio to OCI MTS distributed systems architecture theme"
   git push origin main
   ```
4. Enable **GitHub Pages** under **Settings → Pages → Deploy from a branch (`main` / root)**, or import the repository into **Vercel** for an instant `aayushichoubey.vercel.app` domain.
